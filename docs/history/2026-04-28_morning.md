## 追加修正: 代表選択を情報量スコアに置き換え

### 背景
ID128133 (白フラッシュ, br=184) が ID128134 (破片シーン, br=76) を抑えて
cluster 1589 の rep に居座っていた。旧ロジックは:
- 両方 br < 80 → brightness 高い方 (ロゴフェード対策)
- それ以外 → 顔面積大きい方

動画フレームは顔検出 0 で両方 0 → 入力順最初が永遠に rep。

### 検証で分かったこと
- std だけ: 白フラッシュ (48.9) > 破片シーン (39.9) で **解決しない** (黒い穴の局所コントラストで std が稼げる)
- Laplacian variance だけ: 白フラッシュ (11.1) > 破片シーン (7.2) で **解決しない** (1 箇所の強エッジで稼げる)
- Canny edge density: 0.28% < 0.81% で **破片シーン勝ち** ✓
- 4 指標合算: 6.14 < 9.45 で **破片シーン勝ち** ✓ (entropy が支配的、saturation が補助)

### 実装
`background_worker.py` に 4 つの計測メソッド + 1 つの集約メソッド:

| メソッド | 測るもの | 正規化 |
|---|---|---|
| `_edge_density(gray)` | Canny エッジ密度 (構造分布) | × 100 |
| `_laplacian_variance(gray)` | シャープさ | / 20 |
| `_saturation_mean(img_bgr)` | HSV 彩度平均 (色) | / 25.5 |
| `_shannon_entropy(gray)` | 階調分布の多様性 | そのまま |
| `_info_score(conn, sid)` | 上記 4 つを合算 | 各 0-10 スケール |

代表昇格判定を `if new_score > old_score: _should_promote = True` に統一。
