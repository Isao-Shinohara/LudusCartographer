## 発生した問題と修正 (20 commits)

### A. MOVIE/ADV 判別の構造的再設計 (13 commits)

**根本原因**: HSV色検出が UI金色要素 (コイン, ⊕ボタン, ダイアログ枠) を ⏭ スキップボタンと誤認

| 問題 | 修正 | commit |
|------|------|--------|
| HSV金枠検出が find_golden_highlighted_button で偽陽性 | TAP_HIGHLIGHTED_NAV から HSV を完全廃止、OCRベースに一本化 | 9fd3322 |
| AUTO偽陽性 (score=0.77) でADVと誤判定→動画タップ→一時停止ループ | 証拠ベース判別に再設計: ⏭あり時はAUTO単独を信頼しない | ca1a316 |
| detect_movie_skip_button のHSV金色ブロブが交換所UIを⏭と誤認 | HSVフォールバック完全廃止、テンプレートマッチのみ | d17d423 |
| MOVIE一時停止で500回固定待機 (過剰) | phash静止5フレームで判定、1動画1回の再開上限 | 2c2cc2e, c0e7646 |

**教訓**: **HSV色検出は本プロジェクトでは信頼性が低い**。ゲームUIに金色要素が多すぎるため、色ベースの検出は必ず偽陽性を生む。テンプレートマッチングに統一すべき。

### B. 解像度依存の閾値 (1 commit)

**根本原因**: count_page_dots の面積閾値 (max=400) が 1520x720 固定。2160x1080ではドット面積が2倍超

| 問題 | 修正 | commit |
|------|------|--------|
| ページドット未検出 → MOVIE_INERTIA脱出不発 → MOVIE永久ループ | 面積閾値を解像度比でスケーリング + ROI幅10-90%に拡大 | ac5839d |

**教訓**: `detect_scene_early` は生スクリーンショットを受け取る。ここで呼ばれる関数は全て解像度対応が必要。`detect_and_act` は analysis_path (1520x720) なので影響なし。

## カスケード障害パターン

今回のセッションで繰り返し発生した最も深刻なパターン:

```
HSV/テンプレ偽陽性 → MOVIE誤判定 → OCR抑制 → HOME_REACHED不発 → チュートリアル完了検出不能
```

**防止策** (今回実装済み):
1. HSV完全廃止 → 偽陽性の入口を断つ
2. ポップアップ即棄却 → detect_movie_scene 内で全呼び出し元を保護
3. 証拠ベース判別 → ⏭があっても強いADV証拠があればMOVIE却下
