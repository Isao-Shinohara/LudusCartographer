### 6. 比較ビュー (dHash vs hybrid diff)
GitHub diff 風の 2カラム並列表示。
- Union-Find ペアリング + CSS Grid 行揃え + zebra ストライプ
- 行通し番号 + 枝番ラベル (#0, #0-0, #0-1)
- 各クラスタ代表に★緑バッジ + 橙 ring
- 「差分のみ」「統合のみ」「分離のみ」フィルタ
- カードクリックで詳細モーダル
- キーボードナビ (←→上下) + scroll-margin-top
- ヘッダに判定理由 badge (閾値ベース: dHash<8 / ヒスト類似≥0.5 / 暗転 br<20 等)
- 各カード下に `br:142 dist:4` メタ情報
