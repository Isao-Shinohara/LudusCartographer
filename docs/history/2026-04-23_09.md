## 主な成果

### PilotState / CycleState 分離（最重要）
- 周回リセット漏れバグの根本解決。PilotState（周回引継ぎ6フィールド）と CycleState（周回リセット~78フィールド）に分離
- `reset_for_new_cycle()` → `CycleState()` 再作成で漏れなくリセット
- 全ファイル ~960箇所を `state.cycle.xxx` に書き換え、互換レイヤー削除済み
- **2周目スクショ消失バグ修正**: `state.recorder` が周回リセットで None になり tap_device でスクショ全滅していた

### セッション物理削除機能
- running → discarded → 全画面物理削除
- 未マージ → 全画面物理削除
- マージ済み → 非代表のみ物理削除（マスター参照の代表は保持）
- auto_pilot: discarded 検出→自動新セッション作成

### is_artifact 値分離
- 0=通常、1=Gemini不採用、2=ユーザー不採用（DBレベルで区別可能に）
- タイトル・ドット色・フィルタを分離

### Liveタブ改善
- フィルタ: 採用/不採用/非代表/未処理/すべて の5種に分離
- 同一クラスタパネル追加（代表変更機能付き）
- Shift+クリック: 採用フィルタ→不採用、不採用フィルタ→採用

### クラスタ内バリデーション
- テキスト空メンバーが代表とphash距離>=12なら新クラスタに自動分離

### scrcpy 自動復旧
- adb push ハング時に adb kill-server → restart → scrcpy 再起動（最大3回）

### tap_device スクショスキップログ追加
- スキップ理由（暗転、キャプチャ失敗、重複、例外等）をログ出力
