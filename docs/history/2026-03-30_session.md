# セッション要約 2026-03-30

## 概要
チュートリアル自律操縦の大規模改善セッション。48コミット。
Retina 解像度対応、ホーム画面検出のテンプレマッチ化、金枠検出の暗転判定統一など。

## 主要な修正・改善

### 解像度対応 (根本修正)
- `imread_analysis` 共通ヘルパー追加: ANALYSIS_W×ANALYSIS_H にリサイズしてキャッシュ
- `take_screenshot` で ANALYSIS サイズにリサイズ保存: 全下流関数が正しい解像度を取得
- `AssetManager.match/match_single/match_finger_rotated/match_best_in_roi` を `imread_analysis` に切替
- `find_gold_frame_near`, `detect_movie_skip_button`, `find_3d_arrow` を `imread_analysis` に切替
- `detect_popup_home/detect_popup_home_nav` を `imread_analysis` に切替
- ミニ会話検出の OCR 座標スケーリング修正 (Retina 2880x1440 → 1440x720)

### ホーム画面検出
- OCR ベース → **フッターナビテンプレマッチ** に置換
- 7テンプレ: footer_home_{hikari,gacha,party,pmatch,quest,union,shop}
- 複数バリアント対応 (footer_home_xxx_2.png 等の自動収集)
- ROI: 下部25%

### ホームポップアップ
- `popup_home_next_dark.png` テンプレ追加 (暗背景用)
- ▷検出を ROI (右端30%, 縦中央50%) + light/dark 2テンプレに改善
- 閾値 0.90 → 0.85 (ROI+ドット+ぼかしの複合条件で安全)
- OCR 1件以上を必須化 (動画フレームの誤検出防止)

### 金枠検出 (find_gold_button)
- `detect_tutorial_gold_button_tap` → `find_gold_button` にリネーム
- 内部を `find_gold_frame_near` に委譲 (HSV 統一)
- `right_half_only` 完全削除 → **暗転オーバーレイ判定** (金枠外 std < 45) に統一
- 矩形度 (solidity >= 0.5) チェック追加
- アスペクト比下限撤廃 (横長 HPバー金枠対応)
- 暗転なし + 大面積 (>50000) → 地面テクスチャ除外

### バトル関連
- アニメーション中 (phash 変化大) のシーン転落防止 (BATTLE/MOVIE)
- `_from_battle` フラグのリセット: Result 系以外のアクションで自動解除
- 必殺技演出待機: max 10s→5s, 安定判定 3回→1回
- TUTORIAL_TAP で金枠中心を最優先タップ

### ミニ会話・ADV
- ミニ会話検出: OCR 座標スケーリング + テキスト判定を左右半分+Y範囲に緩和
- `_CONFIRM_POS/NEG_KWS` の検索を完全一致 (exact=True) に変更 (「はい」→「プレイヤーはいません」誤マッチ防止)

### メニュースタック救済
- `_MENU_SCREEN_KWS` 定数追加
- `ineffective_tap_count`: タップ空振り回数 (phash+OCR ファジーマッチ変化判定)
- `handle_menu_stall_recovery`: 5回空振り + メニューKW + icon_back で戻るボタンタップ

### WFC_ESCAPE 改善
- `close_btn` 単独タップを WFC_ESCAPE に統合 (画面遷移中の即タップ防止)
- `close_btn` + OCR テキスト1件以上で発火 (WebView 読み込み待ち)

### 待機時間短縮
- `FORCE_ANALYZE_AFTER_FAST = 2` (MOVIE以外のシーン用)
- MOVIE 待機ログに遷移元シーン表示 (`[ADV_ANIM]`, `[BATTLE_ANIM]`)

### 暗転判定
- `is_dark_screen`: p90 <= 20 → **p90 <= 5** に厳格化
- 暗背景+テキスト画面 (p90=6〜20) は OCR パスに回す

### その他
